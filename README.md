# SDL2 Game Project - 2D Classic Arcade Game

Một trò chơi arcade 2D cổ điển được phát triển bằng ngôn ngữ C++ và thư viện đồ họa SDL2 (Simple DirectMedia Layer) trên môi trường Visual Studio 2022.

# Các tính năng của Game
* **Điều khiển người chơi:** Di chuyển mượt mà thông qua các phím mũi tên hoặc phím WASD/Space.
* **Xử lý va chạm:** Thuật toán phát hiện va chạm chính xác (Bounding Box) giữa nhân vật chính và các chướng ngại vật.
* **Trạng thái game:** Bao gồm màn hình Start Menu, vòng lặp chơi game chính (Gameplay loop) và màn hình Game Over.
* **Quản lý tài nguyên:** Tải và vẽ các tệp hình ảnh (.png, .jpg) làm texture cho nhân vật, nền và chướng ngại vật.
